
Learning in first-order logic (FOL) languages suffers from
the exponential size of hypotheses. This difficulty is traditionally
dealt with by limiting the size of hypotheses, via either
syntatic restrictions or search strategies. In this paper,
we deal with fuzzy first-order logic. 

Similarity can hardly be quantified as either {\it true}
or {\it false}. 
\begin{jlist}
\item Similarity: fuzziness
\item Similarity: context
\item Similarity: personalization 
\begin{jlist}

The user chooses the number of samples to provide in
the relevance feedback loop. This way, the user controls\
the quality and cost of the learning.

Inductive learning produces a set of rules in CNF
Inductive learning can better cope with sparse samples.
Inductive learning can take into account both the links
between attributes and the partial solutions yet available
(background knowledge of the problem).

2. Bottom-Up approach

  Pros:
  o Disjunctive concept is hard to learn top-down
  o Top-down need statistics information
  o When a class involves disjunction of several sub-classes,
    the contributions of the sub-classes add to the global
    criterion that become difficult to interpret.
  o Sensitive to noise, thus fuzzy approach can be better
