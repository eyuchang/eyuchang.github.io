This directory contains the build environment and sample applications (with source code) using the Stanford-Intel DTV API.

You must have DirectX 5 install on your system; however, both Win95 and WinNT are acceptable.
You don't need any special graphics card; however, your processor must be MMXed.
I have tested the code with PentiumII 300 and 350 MHz MMX.

Directory Structure
bin\
    bpc_dtv.dll - Unicorn driver (required for all - live or from file).
    testdec.exe - runs the DTV receiver and MPEG-2 decoder and flips the image using DirectDraw to screen.

include\
    for DTV receiver, include dtv.h
    for DTV receiver plus MPEG-2 decoder, include dtv_mpeg.h

lib\
    for DTV receiver, include dtv.lib
    for DTV receiver plus MPEG-2 decoder, include dtv.lib, dtv_mpeg.lib and mpeg2decoder.lib

sample\
    mydtvapp\                 -     demo of DTV and DTV_MPEG API
    mydtvreceiver\        -    demo of DTV API
    mydtvweb\            -    demo of DTV Object API
