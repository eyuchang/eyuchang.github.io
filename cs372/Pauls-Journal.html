📜 Paul's Missionary Journeys

The Travels of the Apostle Paul across the Roman Empire (c. 46-67 AD)

1st Journey (46-48 AD)
2nd Journey (49-52 AD)
3rd Journey (53-57 AD)
Journey to Rome (59-62 AD)

🟠 First Journey

Route: Antioch → Cyprus → Perga → Antioch Pisidia → Iconium → Lystra → Derbe → Return

Companion: Barnabas, John Mark

⚪ Second Journey

Route: Antioch → Syria → Derbe → Lystra → Troas → Philippi → Thessalonica → Berea → Athens → Corinth → Ephesus → Jerusalem

Companion: Silas, Timothy, Luke

🔵 Third Journey

Route: Antioch → Galatia → Ephesus (3 years) → Macedonia → Greece → Troas → Miletus → Tyre → Caesarea → Jerusalem

Companion: Timothy, Titus, Luke

🩵 Journey to Rome

Route: Caesarea → Sidon → Cyprus → Crete → Malta (shipwreck) → Syracuse → Puteoli → Rome

Status: As prisoner, under Roman guard

✍️ Where Paul Wrote His Letters

📍 Corinth: Romans, 1&2 Thessalonians, Galatians(?)
📍 Ephesus: 1 Corinthians
📍 Macedonia: 2 Corinthians, 1 Timothy, Titus
📍 Rome (Prison): Ephesians, Philippians, Colossians, Philemon, 2 Timothy
