The PBIR Project

Overview

Image database design is an emerging field. To build an image database involves in multiple disciplines including at least image compression, image representation and indexing. In this project, we are interested in exploring new paradigms for building image databases and new applications to use our technology. So far, we have devised new ways to characterize and index images. Our prototype, RIME (an acronym for Replicated IMage dEtector), demonstrates that our techniques can find similar images in a large image database both effectively and efficiently.
