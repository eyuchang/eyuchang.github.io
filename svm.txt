Here's how I prcoessed and analyzed the data:

1) Data pre-processing 
----------------------

* I took the data file fFile1113.dat and for each topic (flowers, people.
architecture etc) I created a separate data file fFile1113.0.dat,
fFile1113.1.dat, ... fFile1113.3.dat that only contained one column for
the label rather than four columns. fFiles113.0.dat had label "1" for all
of the archituecture images and "-1" for all of the other images.
Similarly, fFiles113.1.dat had label "1" for all of the people images and
"-1" for all of the other images. The perl script "mdatSplit" does this
splitting into separate files.

* Each of the four data files were then normalized so that they had zero
mean and variance 1. The perl script "datNormalize" does this task.

2) Learning
-----------

For learning I an assuming a **transductive** learning task. In other
words, we query a few images in our database and then our performance is
measured on the remaining unqueried images in the database (rather than a
separate independent test set).


* Now let's suppose that we concentrate on the architecture
classification task. I took the file fFile1113.0.normalized.dat and
created another file fFile1113.0.normalized.2labels.dat that zeroed out
all of the labels of the images except for one randomly selected positive
image and one randomly selected negative image.

* I then ran the "svm_learn_active" program with the following options:

svm_learn_active -b 0 -o 3 -z 0 -t 1 -d 4 -k fFile1113.0.normalized.dat 
-n 50 fFile1113.0.normalized.2labels.dat
fFile1113.0.normalized.passive.mdl

This does simple random querying until it has seen 50 labeled examples
and uses a SVM with a degree 4 polynomial kernel. The SVM uses the file
fFile1113.0.normalized.2labels.dat as its training set and when it
queries an image it looks up that images label from the fully labeled
file fFile1113.0.normalized.dat.

The transductive SVM option is not used (it hurts the accuracy). The
output will be a set of 49 model files: 
fFile1113.0.normalized.passive.mdl.2 to
fFile1113.0.normalized.passive.mdl.50 corresponding to the SVM learned
after it has seen 2 labeled images up to the SVM learned after it has
seen 50 labeled images.

* Next I ran the "svm_learn_active" program with the following options:

svm_learn_active -b 0 -o 1 -z 0 -t 1 -d 4 -k fFile1113.0.normalized.dat 
-n 50 fFile1113.0.normalized.2labels.dat
fFile1113.0.normalized.simpleactive.mdl

This does simple active querying until it has seen 50 labeled examples
and uses a SVM with a degree 4 polynomial kernel. The transductive SVM
option is not used (it hurts the accuracy). The output will be a set of
49 model files:  fFile1113.0.normalized.simpleactive.mdl.2 to
fFile1113.0.normalized.simpleactive.mdl.50 corresponding to the SVM
learned after it has seen 2 labeled images up to the SVM learned after it
has seen 50 labeled images.


Testing
-------

* The performance of each of the 49+49=98 SVM models were then tested on
the fFile1113.0.normalized.dat data set using "svm_classify". Note that
we have to be careful that we don't test on the images that we've already
seem the label of. I didn't take this effect into account. At the moment
there is only a very slight chance of this happening -- but still, in
principle the svm code needs to be altered to achieve this. 



***IMPORTANT: The Learning and Testing steps were repeated 20 times to
get a good feel as to the performance of each type of querying method.
Running the experiment once is not good enough to gauge the performance.
